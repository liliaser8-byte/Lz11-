## Теоретичні відомості

**Поняття двозв’язного списку та контейнер `std::list**`

**Двозв’язний список** (англ. *Doubly Linked List*) — це динамічна структура даних, що складається з вузлів, кожен із яких містить інформаційне поле (дані) та два вказівники: на попередній (`prev`) і на наступний (`next`) елементи списку.

Наявність двох зв’язків дозволяє ефективно переміщуватися списком як у прямому, так і у зворотному напрямках, а також виконувати вставку й видалення елементів у довільному місці за константний час $O(1)$ за умови наявності ітератора на потрібну позицію.

У стандартній бібліотеці шаблонів C++ (STL) двозв’язний список реалізовано у вигляді шаблонного класу `std::list`. Для роботи з ним необхідно підключити заголовний файл `<list>`. На відміну від масивів та `std::vector`, елементи `std::list` розташовуються в пам’яті не послідовно, тому контейнер не підтримує прямий доступ за індексом (оператор `[]` чи метод `at()` відсутні).

**Основні методи контейнера `std::list**`

| Метод | Призначення та особливості використання |
| --- | --- |
| **`push_back(val)`** | Додає елемент `val` у кінець списку.

 |

 |

 |

 |

 |

**Ітератори та навігація по списку**
**Ітератор** — об’єкт, що дає змогу перебирати елементи контейнера та звертатися до поточного значення. Контейнер `std::list` підтримує двонаправлені ітератори (*Bidirectional Iterators*), для яких визначені операції інкременту (`++it`) та декременту (`--it`), але не підтримується арифметика вказівників (запис `it + 2` є помилкою компіляції).
* **`begin()` та `end()**`: повертають ітератори на перший елемент списку та на умовну позицію після останнього елемента (маркер кінця).
* **`rbegin()` та `rend()**`: зворотні ітератори для обходу списку з кінця на початок (від останнього елемента до позиції перед першим).
* **`std::advance(it, n)`**: функція із заголовка `<iterator>`, що зміщує ітератор `it` на `n` позицій уперед (якщо $n > 0$) або назад (якщо $n < 0$).
* **`std::next(it)` та `std::prev(it)**`: повертають копію ітератора, зміщену на 1 позицію вперед або назад відповідно, не змінюючи сам ітератор `it`.
---

**Основні операції опрацювання**
* **Вставлення та видалення:** метод `insert(it, value)` не робить недійсними ітератори на наявні елементи списку, проте потрібно правильно керувати переміщенням, щоб нові елементи не оброблялися повторно. Після виклику `erase(it)` ітератор на видалений елемент стає недійсним, тому ітератору `it` необхідно присвоювати результат `erase()`, який вказує на наступний елемент.

* **Список структур:** `std::list` може зберігати об’єкти власного типу `struct`, поля якої описують характеристики одного об’єкта. Фільтрація та видалення можуть перевіряти значення полів, а сортування — порівнювати обране поле (наприклад, за допомогою компаратора або лямбда-виразу).

### Код

```cpp
#include <iostream>
#include <list>

using namespace std;

int main() {
    int N;
    cout << "Введіть кількість елементів списку N: ";
    cin >> N;

    // Перевірка, чи є N додатним числом (вимога завдання)
    if (N <= 0) {
        cout << "Помилка: кількість елементів N має бути додатним числом!" << endl;
        return 1;
    }

    list<int> numbers;
    cout << "Введіть " << N << " цілих чисел:\n";
    for (int i = 0; i < N; ++i) {
        int val;
        cin >> val;
        numbers.push_back(val);
    }

    // Виведення початкового списку
    cout << "\nПочатковий список: ";
    for (int x : numbers) {
        cout << x << " ";
    }
    cout << endl;

    // 1. Вставити 25 перед кожним додатним елементом (як у Прикладі 2)
    list<int>::iterator it = numbers.begin();
    while (it != numbers.end()) {
        if (*it > 0) {
            numbers.insert(it, 25);
        }
        it++;
    }

    // Виведення проміжного результату (після вставки)
    cout << "Після вставки 25 перед додатними: ";
    for (int x : numbers) {
        cout << x << " ";
    }
    cout << endl;

    // 2. Вилучити всі від'ємні числа (як у Прикладі 1)
    it = numbers.begin();
    while (it != numbers.end()) {
        if (*it < 0) {
            it = numbers.erase(it); // erase повертає ітератор на наступний елемент
        } else {
            it++;
        }
    }

    // Виведення результуючого списку
    cout << "Результуючий список (після вилучення від'ємних): ";
    for (int x : numbers) {
        cout << x << " ";
    }
    cout << endl;

    return 0;
}
```

**Основні етапи роботи програми:**

1. **Введення та перевірка даних:** Програма запитує кількість елементів `N` і перевіряє, чи є це число додатним. Якщо `N <= 0`, виводиться повідомлення про помилку, і робота завершується. Інакше користувач вводить `N` чисел, які записуються в кінець списку методом `push_back()`.
2. **Виведення початкового списку:** За допомогою циклу `for` програма виводить усі введені елементи на екран.
3. **Вставлення числа 25:** Ітератор `it` проходить від початку до кінця списку. Коли він зустрічає додатний елемент (`*it > 0`), метод `insert(it, 25)` вставляє число `25` безпосередньо перед ним, після чого відображається проміжний стан списку.
4. **Вилучення від'ємних чисел:** Під час другого проходу ітератор перевіряє кожен елемент на від'ємність (`*it < 0`). Якщо число від'ємне, воно видаляється через `it = numbers.erase(it)` — цей метод безпечно видаляє вузол і одразу повертає ітератор на наступний елемент. Якщо число не від'ємне, ітератор просто переходить далі (`it++`).
5. **Виведення результату:** Наприкінці програма друкує фінальний список після всіх змін.

```cpp
#include <iostream>
#include <list>
#include <string>
#include <iomanip>

using namespace std;

// Опис структури Track відповідно до варіанта
struct Track {
    string title;
    string artist;
    int duration;
    int releaseYear;
};

// Допоміжна функція для виведення списку в читабельному вигляді
void printTracks(const list<Track>& tracks) {
    cout << left << setw(22) << "Назва"
         << setw(18) << "Виконавець"
         << setw(15) << "Тривалість"
         << "Рік" << endl;
    cout << string(60, '-') << endl;
    for (const Track& t : tracks) {
        cout << left << setw(22) << t.title
             << setw(18) << t.artist
             << setw(15) << t.duration
             << t.releaseYear << endl;
    }
}

int main() {
    // Створення списку з 5 початкових записів
    list<Track> tracks = {
        {"Shum", "Go_A", 172, 2021},
        {"Intro", "The xx", 85, 2009},
        {"Stefania", "Kalush", 179, 2022},
        {"Solovey", "Go_A", 176, 2020},
        {"Interlude", "Okean Elzy", 65, 2016}
    };

    // 1. Виведення початкового списку
    cout << "Початковий список треків:\n";
    printTracks(tracks);

    // 2. Додавання запису на початок (push_front) і в кінець (push_back)
    tracks.push_front({"Obiymy", "Okean Elzy", 225, 2013});
    tracks.push_back({"Kalyna", "Go_A", 190, 2022});

    cout << "\nПісля додавання на початок та в кінець:\n";
    printTracks(tracks);

    // 3. Фільтрація: вивести треки заданого виконавця (наприклад, "Go_A")
    string targetArtist = "Go_A";
    cout << "\nТреки виконавця \"" << targetArtist << "\":\n";
    for (const Track& t : tracks) {
        if (t.artist == targetArtist) {
            cout << t.title << " (" << t.duration << " сек, " << t.releaseYear << " р.)\n";
        }
    }

    // 4. Видалення за умовою: видалити треки, коротші за 90 сек (за допомогою ітераторів)
    list<Track>::iterator it = tracks.begin();
    while (it != tracks.end()) {
        if (it->duration < 90) {
            it = tracks.erase(it);
        } else {
            it++;
        }
    }

    cout << "\nПісля видалення треків, коротших за 90 сек:\n";
    printTracks(tracks);

    // 5. Сортування за тривалістю зростанням методом sort
    tracks.sort([](const Track& a, const Track& b) {
        return a.duration < b.duration;
    });

    cout << "\nПісля сортування за тривалістю зростанням:\n";
    printTracks(tracks);

    return 0;
}
```
